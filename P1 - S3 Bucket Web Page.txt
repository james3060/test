Step 1: Create an AWS Account
1.	Go to the AWS website and sign up for a free account.
2.	After signing up, sign in to your AWS account.

Step 2: Open Amazon S3
1.	Once signed in, go to the AWS Management Console.
 
2.	In the search bar, type S3 and click on it.
 
Step 3: Create an S3 Bucket
1.	Click on Create Bucket.
 

2.	Enter a unique bucket name (e.g., my-website-bucket).
 
Step 4: Change Public Access Settings.
1.	Scroll down to Block Public Access settings.
2.	Uncheck "Block all public access" to allow the website to be publicly accessible.
3.	Click the Confirm button.
 
Step 5: Finalize Bucket Creation.
1.	Scroll down and click on Create Bucket.
 
 
2.	Once created, click on your bucket name to open it.
 
Step 6: Enable Static Website Hosting
1.	Inside your bucket, go to the Properties tab.
2.	Scroll down to Static Website Hosting and click Edit.
 
3.	Select Enable and set the index document to index.html. (This is the file you will create in the 8th step.)
4.	Click Save changes.

Step 7: Set Permissions (Bucket Policy).
1.	Go to the Permissions tab.
Scroll down to Bucket Policy and click Edit.
  

2.	Click on Add new Statement
 
3.	Look for the Amazon Resource Name (ARN) at the top.
4.	Copy the ARN (it will look something like this: arn:aws:s3:::your-bucket-name).
5.	Add a new policy to make the bucket publicly accessible:
{
	"Version": "2012-10-17",
	"Statement": [
		{
			"Sid": "AllowPublicReadAccess",
			"Effect": "Allow",
			"Principal": "*",
			"Action": [
			    "s3:*"
			],
			"Resource": "arn:aws:s3:::your-bucket-name/*"
		}
	]
}
	
 
6.	Replace your-bucket-name with your actual S3 bucket name.
7.	Click Save Changes.
Step 8: Create an HTML File
1.	Open Notepad (or any text editor).
2.	Copy and paste the following HTML code:

<!DOCTYPE html>
<html lang="en">

<head>
    <title>Html Forms</title>
</head>

<body>
    <h2>HTML Forms</h2>
    <form>
        <label for="username">Username:</label><br>
        <input type="text" id="username" name="username"><br><br>

        <label for="password">Password:</label><br>
        <input type="password" id="password" name="password"><br><br>

        <input type="submit" value="Submit">
    </form>
</body>
</html>


3.	Save the file as index.html.



Step 10: Upload the HTML File to S3
1.	Go back to your S3 bucket and click on Objects.
 
2.	Click Upload → Add Files → Select your index.html file.
3.	Click Upload.
Step 11: Open Your Website
1.	Click on index.html inside the S3 bucket.
2.	Copy the Object URL and paste it into your browser.
 
3.	Your static website is now live!
