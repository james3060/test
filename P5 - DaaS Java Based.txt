Step 1: Prepare Your Files
Before deployment, ensure your project contains these files:
📂 my-website
├── index.html (Main webpage)
├── style.css (For styling/design)
├── script.js (For JavaScript functionality)

	index.html (Basic webpage structure)
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Simple Web App</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>My Simple Web App 🚀</h1>
    <p id="message">Click the button below:</p>
    <button onclick="changeText()">Click Me</button>

    <script src="script.js"></script>
</body>
</html>
	style.css (Styling the page)
body {
    font-family: Arial, sans-serif;
    text-align: center;
    margin: 50px;
    background-color: #f4f4f4;
}

button {
    font-size: 16px;
    padding: 10px 20px;
    cursor: pointer;
}


	script.js (Adding JavaScript functionality)

function changeText() {
    document.getElementById("message").innerText = "You clicked the button! 🎉";
}



Step 2: Open Netlify
1.	Go to https://www.netlify.com/
2.	Sign up or log in (You can use Google, GitHub, or Email).
  




 Step 3: Upload Your Files
1.	Click on "Add new site" → "Deploy manually"
 
2.	Drag & drop your entire project folder (my-website) into Netlify.
 
 
3.	Wait a few seconds – Netlify will upload your files.
Step 4: Get Your Website Link
✅ Your website is now LIVE!
Netlify will generate a link like:
🔗 https://your-site-name.netlify.app
You can now share, update, or customize your site!
