Part 1: Creating an EC2 Instance
Step 1: Sign in to AWS
●	Open AWS Management Console in your browser.

●	Enter your AWS email and password to log in.

Step 2: Open EC2 Dashboard
●	In the AWS search bar, type EC2 and select it.

●	This will take you to the EC2 Dashboard where you manage virtual servers.
 



Step 3: Launch an Instance
●	Click on Launch Instance to create a new virtual machine.
 
Step 4: Choose an Amazon Machine Image (AMI)
●	Give a name to your instance.

●	Choose an Amazon Machine Image (AMI) – a pre-configured operating system (Select a Free Tier AMI for practice).
 




Step 5: Create or Select a Key Pair
●	A key pair is needed for secure SSH access to your instance.

●	If you have a key pair, select it.

●	If you don’t, create a new one, download the .pem file, and store it securely (you need this to connect to the instance).
 
Step 6: Keep Default Network Settings
●	Use default settings for networking. No changes are needed.
Step 7: Launch Instance
●	Check the acknowledgment box and click Launch Instances.
 
 

Step 8: View Your Running Instance
●	Once launched, go to the Instances page to see your instance running.
 







Part 2: Migrating an EC2 Instance to Another Region
Step 1: Create an Image of Your Instance
●	Right click on your running instance → Image and Templates → Create Image.

OR

●	Select your running instance, click Actions → Image and Templates → Create Image. 

 
Step 2: Provide Details for the Image
Give your image a name and click Create Image.
 


Step 3: View the Created Image
●	Go to AMIs (Amazon Machine Images) to see your newly created image.

●	Wait until the status is "Available".
 

Step 4: Copy the AMI to Another Region
●	Right-click on the AMI → Click Copy AMI.
 



Step 5: Select Destination Region
●	Choose a Destination Region where you want to migrate.
 
Step 6: Switch to the New Region
●	Go to the region selector (top right corner of AWS).

●	Select the destination region where you copied the AMI.

 
Step 7: Launch a New Instance from the Migrated AMI
●	Go to AMIs, right-click the copied image, and select Launch Instance.

●	Follow the same steps as before to set up networking and a key pair.

●	Click Launch to start the migrated instance in the new region.
